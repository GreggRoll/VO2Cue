# VO2Cue public pages

GitHub Pages publishes `main` → `/docs` from the `GreggRoll/VO2Cue` repository.

- Demo: `https://greggroll.github.io/VO2Cue/` → `index.html`
- Privacy: `https://greggroll.github.io/VO2Cue/privacy` → `privacy/index.html` (the static host adds the trailing slash)
- Legacy demo subpath: `/VO2Cue/demo/` redirects to the demo root and preserves its query and fragment.

The capitalized project route depends on the GitHub repository being named `VO2Cue`. A nested `docs/VO2Cue/` directory would produce an extra path segment and is not used.

Current screenshots, the two widget sizes, and a completed-goal example are generated by `output/app-store-screenshots/compose_screenshots.py`. The original simulator data is restored after capturing example sessions. The widgets use example totals of 42/60 active minutes; the completed-goal example uses a personal goal of 40 minutes.

When publishing the new routes, also set the App Store Connect Privacy Policy URL to `https://greggroll.github.io/VO2Cue/privacy`. The app's next build links to this address through `PurchaseConfiguration.privacyURL`. Renaming a GitHub project does not automatically redirect its old Pages URL.

Verification includes all relative page/image/stylesheet links, desktop and mobile previews at 320, 390, and 768 pixels, and the six 1242 × 2688 iPhone screenshot dimensions. Preview evidence is saved in `output/site-preview/`.
