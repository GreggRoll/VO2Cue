# VO2Cue public pages

GitHub Pages publishes `main` → `/docs` from the `GreggRoll/VO2Cue` repository.

- Landing page: `https://greggroll.github.io/VO2Cue/` → `index.html`
- Privacy: `https://greggroll.github.io/VO2Cue/privacy/` → `privacy/index.html` (canonical trailing-slash URL)
- Legacy demo subpath: `/VO2Cue/demo/` redirects to the demo root and preserves its query and fragment.

The capitalized project route depends on the GitHub repository being named `VO2Cue`. A nested `docs/VO2Cue/` directory would produce an extra path segment and is not used.

Current screenshots, the two widget sizes, and a completed-goal example are generated by `output/app-store-screenshots/compose_screenshots.py`. The original simulator data is restored after capturing example sessions. The widgets use example totals of 42/60 active minutes; the completed-goal example uses a personal goal of 40 minutes.

When publishing the new routes, also set the App Store Connect Privacy Policy URL to `https://greggroll.github.io/VO2Cue/privacy/`. The app's next build links to this address through `PurchaseConfiguration.privacyURL`. Renaming a GitHub project does not automatically redirect its old Pages URL.

Verification includes all relative page/image/stylesheet links, desktop and mobile previews at 320, 390, and 768 pixels, and the six 1242 × 2688 iPhone screenshot dimensions. Preview evidence is saved in `output/site-preview/`.

## Search and accessibility maintenance

The homepage includes `MobileApplication`, `WebPage`, `WebSite`, and developer JSON-LD, visible product answers, Open Graph/Twitter metadata, and a static sitemap. The visible US App Store price and rating were checked against Apple's public listing and lookup API on October 19, 2026. Update the visible facts, their check dates, matching JSON-LD, and sitemap modification date together when they change. Do not publish planned features as released behavior.

`https://greggroll.github.io/robots.txt` is served by the separate `GreggRoll/GreggRoll.github.io` repository. A `robots.txt` inside this project's `/docs` folder would be served below `/VO2Cue/` and would not control crawlers. The root policy preserves open access and advertises this site's sitemap. Submit `https://greggroll.github.io/VO2Cue/sitemap.xml` in Google Search Console and Bing Webmaster Tools once signed in.

Rebuild optimized header, favicon, touch, and responsive screenshot assets with `python3 scripts/build-site-images.py` (Pillow required). Render the 1200 × 630 share card with `node scripts/build-social-preview.cjs` (Playwright and Chromium required; optional `CHROME_PATH`). Both scripts retain the original artwork and screenshots as their source.

Before publishing, check relative links and responsive image candidates, parse the JSON-LD and sitemap, and inspect the page at 320, 390, 768, and 1440 CSS pixels. Include keyboard skip-link/focus behavior, reduced motion, and 200% text resizing. The hero caption is in normal document flow so enlarged text cannot overlap the device artwork. Keep headings, product answers, and download links available without JavaScript.

`docs/indexnow-key.txt` is a public ownership-verification file scoped to `/VO2Cue/`. After a substantive update is live, run `python3 scripts/notify-site-update.py` to notify participating IndexNow search engines of the two sitemap URLs. This does not submit to Google or guarantee indexing.
